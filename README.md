# 一期 · 习惯

个人、手机优先、本地优先的习惯 PWA。零运行时依赖、无账号、无后端、无分析追踪。源码直接位于 `dist/`，无需打包。

## MVP

- 进行中：今日执行、积分、每期进度和详情。
- 习惯模板：创建、编辑、停用/恢复、开始新一期、历史期数。
- 奖励：全局余额、自定义奖励和价格、确认兑换、兑换历史。
- 历程：完成/提前结束的周期、完成过的习惯、日期、执行记录与完成率。
- 数据：JSON 全量导入/导出、版本/引用/积分一致性校验、覆盖前确认。
- PWA：主屏幕安装、应用图标、离线缓存；首次访问需要网络。

## 数据模型（schemaVersion: 2）

| 集合 | 内容 |
| --- | --- |
| templates | 名称、图标、难度、单次积分、停用标记 |
| cycles | 模板 ID、开始/计划结束日期、模板设置快照、本期执行频率、状态、实际结束日期 |
| checkins | 周期 ID、本地日期、当次积分；周期 + 日期唯一 |
| rewards | 名称、积分价格、停用标记 |
| redemptions | 奖励 ID、兑换时名称/价格、时间 |

余额 = 全部打卡积分 − 全部兑换价格，不重复存余额。更改模板和奖励不改写历史。采用 localStorage 原子保存一个版本化 JSON；写入失败不更新内存，多标签冲突先刷新再重试。不做永久连续打卡天数。

## 明确的规则

- 每期单独选择每天、每周指定日期或每周 X 次；每期每天最多打卡一次，支持当天打卡，以及本周一至昨天的补打卡（按设备本地日期）。补卡仅限未归档周期内的可执行日，与当天打卡共享每周次数上限，获得相同积分；不支持撤销补卡。
- 每周 X 次按周一到周日统计（1–7 次），执行日自由安排。首尾不足一周时目标为 min(X, 可执行天数)。达到当周目标后不能额外计分，未完成次数不跨周累计；详情中的截至本周目标包含当前整周目标。
- 模板只保存名称、40 种图标之一、难度与积分，不保存频率。v1 本地数据和备份自动升级到 v2，以每个旧周期快照中的频率为准，保留历史和积分。
- 同一模板同一时间只允许一个未归档周期；支持未来开始；首尾日期均包含，最长 10 年。
- 1/4/6/12 月为日历月，结束日取下一个月边界的前一天；月底按目标月最后一天夹取。
- 到期不自动成功，用户确认完成归档；提前结束时，零打卡的周期直接删除，不计入历史期数，模板保留；有打卡的周期单独归档，仍保留已得积分。
- 完成率 = 打卡次数 / 整个原计划的应执行次数。提前结束不缩小分母，详情另显示截至结束时的应执行次数。
- 今日打卡可撤销；若积分已消费且当前余额不足，则不能撤销。兑换确认后保留，不提供取消兑换。
- 模板/奖励软停用，不删除历史；归档后记录只读。
- 初始模板和奖励是可编辑的建议，没有虚构的执行记录或余额。
- 不做登录、后端、云同步、推送、RPG、任意复杂重复规则或任务树。

## 运行和验证

需要 Python 3（静态服务器）和 Node 22+（测试）。

```sh
npm run dev
npm test
```

打开 http://127.0.0.1:5173 。手机安装需要 HTTPS 托管；手机访问电脑普通 HTTP IP 不满足 Service Worker 安全上下文要求。

数据属于固定网址、浏览器/安装入口；换域名、换设备、清除网站数据前先导出。iOS 安装请使用 Safari 分享菜单的「添加到主屏幕」。本地存储不是长期备份，建议每月导出并另存一份。

静态部署上传 `dist/` 全部文件即可。更新应用时递增 `sw.js` 的 CACHE 版本；新缓存就绪后可点击更新（先保存/关闭表单），也可以关闭全部旧页面后重新打开，避免离线混用不同版本。不将个人数据加入应用缓存或源码。

## GitHub Pages

仓库包含 `.github/workflows/pages.yml`。在 GitHub 仓库的 Settings → Pages 中，将 Source 设置为 GitHub Actions。推送到 `main` 或手动运行工作流后，先执行核心测试，再发布 `dist/`；不会上传浏览器本地记录。

所有应用资源、安装入口和 Service Worker 均使用相对路径，支持项目网站的 `/仓库名/` 子路径。离线缓存按网站路径隔离。更新资源时递增 `dist/sw.js` 的缓存版本。

发布成功后，以工作流输出的 HTTPS 地址为准：

- iPhone：Safari 打开 → 分享 → 添加到主屏幕。
- Android：Chrome 打开 → 菜单 → 安装应用 / 添加到主屏幕。
- 迁移现有记录：在电脑本地应用中导出 JSON，通过 AirDrop 或文件传到手机，在安装后的应用中导入。

`127.0.0.1` 只指向当前设备，不能把电脑上的这个地址直接放到手机访问。GitHub Pages 是公开的网站入口，但习惯、打卡和积分数据只留在每个使用者自己的浏览器中。不同设备不会自动同步。
